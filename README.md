**Play:** after GitHub Pages is on — `https://sl8722569-ux.github.io/insan-cricket/web/`

The playable build is expanded from the user's `INSAN_CRICKET_3D_PREMIUM_GAMEPLAY_FIXED-1.html` (preserved in `original/`).
