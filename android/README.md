# Android APK (INSAN CRICKET)

Official **WebView wrapper** of the live PWA:

https://sl8722569-ux.github.io/insan-cricket/web/

This is a real installable APK (camera + microphone permissions). It is **not** a rewrite of the Windows Python app.

Sideload `INSAN-CRICKET-Android.apk` from Releases. Debug-signed WebView of the live PWA. Not a Play Store listing.

The Android web companion ZIP is a separate file: Chrome → Add to Home screen.
